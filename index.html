Negative Space

Carved from real building volumes · Hudson Yards

How this works

What this is

Takes a bounding "mold" volume the size of a chosen NYC neighborhood — footprint × tallest building — and subtracts every real building from it. What's left is the negative space: the shape of the air around and above the buildings, capped by the mold's own outer boundary.

Getting started

Neighborhood
Pick a real, pre-built site from the dropdown. Each one is real Overture Maps building data, not a live search-any-area system.
Compute negative space
Runs the boolean subtraction. Needed once per neighborhood before Negative space, the cutaway sliders, or poché become available.
Buildings / Negative space
Toggle which layer you're looking at.

Exploring the cut

Height / X / Y cutaway
Sliders carve away one octant of the mold, corner by corner, so you can look inside. Flip X / Flip Y switch which side gets carved.
Section fill (poché)
Shades the cut faces translucent red, architectural-section style — the boundary of the void itself.
3D drag handles
The small handles on the exposed corner can be dragged directly in the viewport instead of using the sliders.

Navigation

N / S / E / W
True flat orthographic elevations (no perspective foreshortening) — an actual architectural elevation, not just a rotated 3D view.
P (Plan)
True straight-down orthographic plan view, north-up.
⌂ (Home)
Returns to the default 3/4 perspective view, framed to the current model.
Compass
Needle always points at real true north, corrected for Manhattan's own ~29° street-grid tilt.

Context

Manhattan context
Zooms out to show the neighborhood's real position on the island.
Major streets
Real NYC avenue-and-up streets (Street Centerline data) around the site.
